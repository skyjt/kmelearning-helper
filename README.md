# KME 学习助手（kmelearning-helper）

> 一个给 `pc.kmelearning.com` 学习页用的自动学习助手，提供 Chrome 扩展（Manifest V3）和油猴脚本两个版本。
> 它会在页面右下角放一个“学习助手”浮窗，登录后列出「我的任务」中的未完成任务；经你确认后进入对应任务，按目录顺序自动播放课程、等平台确认完成，再调用你配置的大模型完成测验并继续下一门课程。

---

## 为谁而做

如果你是 **江苏农商行** 的员工，大概率对「学习地图」不陌生：一张图里排着几十门必修课，每一门都要手动点开、从头看到尾、等系统确认完成、再返回点下一门……一轮下来，光是点击和干等就耗掉大半天，真正的注意力却很难留在内容上。

**这个助手就是为这群人做的**——把「点开 → 等播完 → 返回 → 下一门」这套机械重复交给浏览器自动完成，把时间还给真正需要动脑的工作和学习。

> 它按平台规则**老老实实地以 1x 播放**，不跳过、不伪造完成，所以同样适用于其他跑在 `pc.kmelearning.com` 上的学习平台。

---

## 这是什么

登录后，平时你要做的事是：找到未完成任务 → 进入任务 → 点「进入学习」→ 点开一门课 → 等它播完 → 返回列表 → 再点下一门……重复几十遍。

这个助手把这套重复操作自动化：

```
登录首页，自动检测未完成任务
   │
   ├─▶ 在浮窗选择任务并确认
   │      └─ 自动进入任务详情和课程目录
   │
   ├─▶ 进入第一门未完成课程
   │      └─ 自动播放（锁定 1x），等平台显示“完成”
   │
   ├─▶ 遇到课程测验
   │      └─ 自动分析题目、填写、确认提交，等待通过结果
   │
   ├─▶ 返回上一级课程列表
   │
   └─▶ 继续下一门未完成课程 …… 直到全部学完
```

**它做的：** 减少重复点击，按平台规则播完每门课；遇到测验时将可见题目发送给自定义模型，自动填写、提交，并在通过后继续学习。
**功能边界：** 不倍速、不伪造完成状态、不读取平台隐藏答案字段；图片题、模型异常、回填失败或未通过时会停止自动学习。

## 为什么默认不倍速、不跳过

`pc.kmelearning.com` 判断一门课是否完成，**不只看视频有没有播到结尾**，而是综合了心跳、真实学习时长、播放进度和完成状态。

所以：

- ❌ 第三方倍速插件就算把视频播完，也可能因为真实学习时长不够而不算完成。
- ❌ 直接拖进度条到结尾、或跳过播放，通常过不了平台的完成判断。
- ✅ 本扩展默认锁定 **1x**，平台没确认完成时就按 1x 补学 / 重播，稳稳通过。

## 快速开始

### 1. 选择安装方式

**方式一：油猴脚本（推荐）**

1. 先安装 [Tampermonkey](https://www.tampermonkey.net/) 等用户脚本管理器。
2. 点击 [安装 KME 学习助手油猴版](https://raw.githubusercontent.com/skyjt/kmelearning-helper/main/userscript/kme-learning-helper.user.js)。
3. 在脚本管理器打开的安装页确认安装。
4. 打开或刷新 `https://pc.kmelearning.com/` 学习页面。

油猴版会跟随仓库里的版本号检查更新，核心功能和 Chrome 扩展保持一致。

**方式二：Chrome 扩展**

下载 ZIP：

1. 打开 GitHub 仓库页 → 点 `Code` → `Download ZIP`，下载后解压。
2. Chrome 地址栏进入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选中解压后的文件夹（里面要有 `manifest.json`）。

也可以用 Git 克隆：

```bash
git clone https://github.com/skyjt/kmelearning-helper.git
```

然后同样在 `chrome://extensions` 里 **加载已解压的扩展程序**，选中克隆下来的目录。

> 同一个浏览器请只启用一个版本，避免运行状态和设置来源混淆。

### 2. 开始学习

1. 登录 `pc.kmelearning.com`，回到首页。
2. 学习助手会自动展开，并列出「我的任务」中的未完成任务。
3. 点击准备学习的任务，在提示中点 **确认开始**。
4. 保持标签页打开，助手会自动进入任务和课程目录，再按“播完 → 返回 → 下一门”的顺序往下学。

也可以直接进入某个课程目录页，再点 **开始自动学习**，继续使用原有的目录学习方式。

> 💡 浮窗可以最小化成右下角的小图标，点一下或鼠标移上去就能展开。

## 功能一览

- 📋 登录首页后自动检测未完成任务，在浮窗中显示任务列表。
- ✅ 选择任务后先二次确认，再自动进入任务详情和课程目录。
- 🪟 在学习目录页显示“学习助手”浮窗，并实时显示当前目录的**总进度**。
- ▶️ 点“开始自动学习”后，自动进入第一门未完成课程并播放。
- 📄 视频会自动播放；文档 / 材料类页面会保持活跃并等待完成标记。
- 🔁 一门课内容学完后，自动返回上一级课程列表，继续下一门。
- ⏱️ 返回前会检查课程记录里的“学习总时长”，不够课程要求学时就按 1x 继续补学。
- 🤖 可配置 OpenAI-compatible 大模型接口，自动提取单选、多选和判断题，填写全部有效答案并提交。
- 🔄 测验通过后自动进入下一项或下一门课程；模型分析失败最多重试两次，仍失败就停止学习。
- ⏭️ 不使用 AI 时，仍可自动跳过考试、测验、问卷、作业等需要人工完成的页面。
- 🧭 关闭“全自动答题并提交”后，可继续使用答案预览和手动回填模式。
- 🛡️ 默认抵消第三方倍速带来的“播完却不算完成”问题。

## 设置项

点浮窗右上角的 **⚙**，卡片会**翻转**到背面的设置面；开关下面这些行为，改完点「**完成**」翻回正面即可（改动即时生效）：

| 设置 | 作用 |
| --- | --- |
| **自动播放** | 进入课程后自动开始播放视频 |
| **未完成自动补学** | 视频播完但平台没确认时，自动按 1x 重播补足 |
| **总时长达标再返回** | 返回列表前检查学习总时长是否达到课程要求 |
| **AI 自动答题** | 遇到测验时调用已配置模型；开启后会自动关闭“跳过做题页” |
| **全自动答题并提交** | 自动关闭须知、分析、填写、确认提交，并在通过后继续学习 |
| **跳过做题页** | 遇到考试 / 测验 / 问卷 / 作业自动跳过 |

「AI 自动答题」与「跳过做题页」互斥，开启其中一项会自动关闭另一项。

> 视频按平台规则**固定以 1x 播放**（确保积累真实学习时长），这是核心行为，已不再作为可关闭的开关。

## AI 自动答题

当前版本支持 **OpenAI-compatible Chat Completions** 接口，推荐使用油猴版：

1. 点浮窗右上角 **⚙**，开启 **AI 自动答题** 和 **全自动答题并提交**。
2. 填写完整接口地址，例如 `https://example.com/v1/chat/completions`。
3. 填写模型名称和 API Key；本机免鉴权接口可以留空 Key。
4. 点 **测试模型连接**，确认接口可用，再点「完成」返回正面。
5. 点 **开始自动学习**。视频和学习时长完成后，助手会自动进入测验、关闭须知、请求模型、填写全部有效答案并提交。
6. 平台显示通过后，助手会校验课程总学习时长；达标后继续下一项或返回课程列表学习下一门课程。

全自动流程最多请求模型两次。模型未返回完整答案、图片题、页面回填失败、找不到提交按钮、结果未通过或超时都会停止自动学习，避免重复提交。关闭 **全自动答题并提交** 后，会恢复答案预览、手动回填和人工提交。

API Key 默认只保留到当前页面刷新；开启「记住 API Key」后才会存入油猴脚本自己的本地存储。发送给模型的内容限定为课程标题、页面可见题干和选项，不包含平台 Cookie、用户资料或隐藏判题数据。

> 油猴首次访问新模型域名时会请求跨域授权。请核对目标域名，只允许你信任的模型服务。Chrome 扩展版使用浏览器 `fetch`，模型服务需要正确配置 CORS；任意自定义接口优先使用油猴版。

当前版本暂不处理图片题。检测到图片题时会停止 AI 分析并提示人工完成。

## 常见问题

**浮窗没出现？**
确认你在 `pc.kmelearning.com` 的学习页，并刷新一次页面。第一次安装后已打开的页面需要刷新才会注入。

**学了一会儿停住了？**
平台页面结构更新可能导致识别失效。先刷新页面重试；仍有问题再更新扩展代码。

**视频播放了，为什么「记录」里的学习总时长暂时没变化？**
平台的「记录」页只在打开时请求一次数据，停留在该页时数字不会持续跳动。v2.7.1 起，学习助手会在课程完成校验前自动刷新该页，等最新总时长加载完成后再决定是否补学。

**AI 模型连接失败？**
确认接口地址包含完整的 Chat Completions 路径、模型名称准确，并检查 API Key、账户额度和油猴弹出的域名授权。远程接口必须使用 HTTPS，本机接口可使用 `localhost` HTTP。

**全自动答题为什么停住了？**
浮窗会显示停止原因。常见原因包括图片题、模型两次都没有返回完整 JSON、页面选项写入失败、提交按钮未识别、测验未通过或提交结果超时。修正配置或人工处理后，再点“开始自动学习”重试。

**能配合倍速插件用吗？**
不建议。平台会校验真实学习时长和心跳，倍速播完往往不算完成，反而拖慢进度。

## 开发

```bash
npm install        # 安装依赖
npm test           # 运行 Playwright 烟雾测试
npm run build:userscript  # 重新生成油猴单文件
npm run icons      # 重新生成图标
```

打包本地安装用的 ZIP：

```bash
mkdir -p dist
zip -r "dist/kmelearning-helper-v$(node -p "require('./manifest.json').version").zip" \
  manifest.json content.js styles.css icons README.md INSTALL.md LICENSE
```

### 文件结构

| 路径 | 说明 |
| --- | --- |
| `manifest.json` | Chrome MV3 扩展配置 |
| `content.js` | 注入到学习页面的核心逻辑（含翻转设置面） |
| `styles.css` | 浮窗、翻转设置面和控件样式 |
| `icons/` | 扩展图标 |
| `userscript/kme-learning-helper.user.js` | 可直接安装的油猴单文件（自动生成） |
| `tests/extension-smoke.mjs` | 同时覆盖 Chrome 版和油猴版的 Playwright 烟雾测试 |
| `tools/build-userscript.mjs` | 从共享核心、样式和图标生成油猴单文件 |
| `tools/generate-icons.mjs` | 图标生成脚本 |
